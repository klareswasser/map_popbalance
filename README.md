# 国勢調査 メッシュ別年齢階級人口分析

## 目的
令和2年（2020年）国勢調査の250m/500mメッシュ別5歳階級別人口データを用いて、年齢分布の偏り（特異な人口ピラミッド）を持つ地域を抽出・可視化する。

## 分析アプローチ案

### 1. ジニ係数を用いたアプローチ
- **概要**: 5歳階級（0-4歳, 5-9歳, ..., 95歳以上）の人口分布からジニ係数を計算し、年齢構成の「偏り」を定量化する。
- **課題**: 通常、ジニ係数が高い地域＝超高齢化地域（高齢者層が極端に多い）となる傾向が強い。
- **解決策**:
  - 全体のジニ係数を算出した後、65歳以上を除外した「生産年齢＋若年層ジニ係数」を併算する。
  - または、「平均年齢・高齢化率」と「ジニ係数」の散布図を作成し、**高齢化率が低いのにジニ係数が高い（＝30代や40代など特定の世代が突出して多い）メッシュ**を抽出する。

### 2. 人口ピラミッドのクラスタリング
- **概要**: メッシュごとの「5歳階級別男女比率（パーセンテージ）」を特徴量ベクトルとして、K-Means 等でクラスタリングを行う。
- **利点**:
  - 直感的に「学生街型（20代突出）」「ニュータウン型（30〜40代と10歳未満が突出）」「限界集落型（高齢層突出）」などの典型的な人口ピラミッド形状を自動分類できる。
  - 各クラスタの重心（クラスタセンター）を可視化することで、どのような形状の分布が存在するか一覧可能。

## 想定される作業手順
1. ダウンロード済みデータの結合・整形（T001192 / T001196）
2. 各メッシュの人口構成比、平均年齢、高齢化率、年齢ジニ係数の算出
3. クラスタリングの実施および結果の地図可視化（Kepler.gl / Folium / matplotlib 等）
